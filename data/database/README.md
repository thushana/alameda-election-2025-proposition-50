# Database Files

SQLite database files for CVR data analysis.

- `cvr-data.db` - Main SQLite database containing CVR export data
- `cvr-data.db-shm` - Shared memory file (auto-generated)
- `cvr-data.db-wal` - Write-ahead log file (auto-generated)

Generated by `scripts/load-cvr-to-sqlite.ts` from CVR export data. Used by analysis scripts for cross-contest analysis.
